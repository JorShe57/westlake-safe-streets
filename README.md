# Westlake Safe Streets — SS4A Public Input & Engineering Hub (Prototype)

Interactive frontend prototype built for the **City of Westlake, Ohio** Department of Engineering to demonstrate public engagement, GIS export, and long-term Action Plan tracking for the **Safe Streets and Roads for All (SS4A) Comprehensive Safety Action Plan**.

## Features
- **Public Safety Map:** Westlake-bounded interactive map (OpenStreetMap + Esri Aerial/Satellite toggle), verified Westlake intersections, address/intersection search + GPS, click-to-drop safety pin reporting, upvoting ("I've Seen This Too"), resident notes, and a toggleable sample High-Injury Network (HIN) corridor overlay.
- **Community Survey (Task 5):** Dedicated, mobile-friendly multiple-choice survey capturing travel behavior, priorities, and accessibility barriers.
- **Engineering & GIS Portal (Deliverables 4 & 9):** KPI summary, top hotspots, category breakdown, agency jurisdiction triage (`City of Westlake`, `Cuyahoga County`, `ODOT / State Route`), and one-click **GeoJSON** (ArcGIS/QGIS) and **CSV** (public records) exports.
- **Action Plan Tracker (Deliverable 6 & Task 8 Preview):** Illustrative prioritized project database linking resident confirmations to engineering countermeasures, cost estimates, lead agencies, and grant sources.

## Run Locally
```bash
npm install
npm run dev
```
